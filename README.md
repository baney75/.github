# baney75/.github

Shared GitHub settings for [baney75](https://github.com/baney75)'s repositories.

- `FUNDING.yml` adds the Sponsor button to every repository: [GitHub Sponsors](https://github.com/sponsors/baney75) and [dbaney.com/support](https://dbaney.com/support/).
- `.github/workflows/sponsors.yml` is a reusable workflow. Each project calls it daily and on every release, so public sponsors are credited in its README and release notes without anyone editing them by hand.
